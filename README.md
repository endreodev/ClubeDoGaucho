# Plugin para Integração de Compras e Regras de Pagamento

Este plugin foi desenvolvido com os seguintes objetivos principais:

- **Integração de Histórico de Compras:**  
  Fornecer uma API para enviar informações de compras realizadas pelo cliente na loja física para o site, permitindo acesso ao histórico de compras diretamente pelo cliente.

- **Filtros de Formas de Pagamento no Checkout:**  
  Aplicar regras específicas para filtrar as formas de pagamento disponíveis no checkout, baseando-se em critérios definidos pelos valores de consumo do cliente.

---

## 🛒 Recursos

- **Envio de Dados de Compras:** Sincroniza as informações entre loja física e site.
- **Gestão de Regras de Pagamento:** Personaliza o checkout com base nas condições do cliente.
- **Foco no Cliente:** Melhora a experiência de compra com mais acessibilidade e opções no site.
